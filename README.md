# ТРУБПРОМ — справочник труб

**Живая версия: https://etozhegatito.github.io/truby-catalog/**

Статический сайт-каталог видов труб: 33 позиции с описанием конструкции, технологии
производства, области применения, сортамента и ГОСТов. Плюс три сервиса: калькулятор
веса, сравнение труб и FAQ.

## Как открыть

Просто дважды кликните `index.html` — сайт откроется в браузере и полностью
заработает. Ни интернета, ни сервера, ни установки чего-либо не требуется:
внешних библиотек, шрифтов и картинок нет вообще.

Если нужен локальный сервер (например, чтобы посмотреть с телефона в той же сети):

```bash
python3 -m http.server 8000
```

## Презентация

`presentation.html` — короткий деск на 15 слайдов: как делают трубы, история в четырёх датах,
виды и размеры, данные по рынку, вопросы для подбора трубы и для продажи комплекта.

- листается стрелками ← → или колесом мыши, точки навигации справа
- готовый **PDF 16:9** лежит рядом: `trubprom-presentation.pdf` (кнопка «Скачать PDF» на первом слайде)
- пересобрать PDF после правок: `make-pdf.sh` или `Ctrl/⌘ + P` в браузере
- **каждое фактическое утверждение снабжено сноской на источник**, полный список — на последнем слайде;
  слайды, основанные на отраслевой практике, а не на исследовании, помечены явно

Цвета графиков (`#2a78d6`, `#eb6834`) проверены на различимость при дальтонизме и на контраст
относительно светлой подложки.

## Текст для рассказа

`speech.md` — связный текст на ~25 минут чтения вслух: что такое труба, история от
Месопотамии до процесса Маннесмана, способы производства, разбор характеристик,
все виды труб с размерами, области применения и трезвый раздел о будущем отрасли.
Про устройство сайта в тексте ничего нет — это материал о самих трубах.

Все числовые утверждения снабжены ссылками на источники, список в конце файла.

## Картинки труб

Внешних изображений нет — и «фотография» трубы, и схема сечения со слоями рисуются
векторно (SVG) прямо в браузере из описания в `data.js`. Поэтому сайт весит меньше
мегабайта, работает офлайн и одинаково выглядит на любом экране.

За вид отвечает блок `visual` у каждой трубы:

```js
visual: {
  wallFrac: 0.55,                 // какую долю радиуса занимает стенка
  surface: 'layered',
  layers: [                       // слои снаружи внутрь, t — доля стенки (сумма = 1)
    { n: 'ПЭ-оболочка',          c: '#22262c', t: 0.16 },
    { n: 'Пенополиуретан (ППУ)', c: '#f2cd76', t: 0.62 },
    { n: 'Стальная труба',       c: '#8d99a6', t: 0.22 }
  ],
  wires: true                     // доп. детали: wires, thread, coupling,
}                                 // socket, spiral, seamLine, corrugated, stripe
```

Если хотите поставить настоящие фотографии — положите файлы в `assets/img/`
и добавьте `<img>` в шаблон карточки (`cardHTML` в `app.js`) и на страницу трубы
(`pageHTML` в `pipe.js`).

## Блок «здесь будет контакт поставщика»

Заглушка на странице каждой трубы. Чтобы подставить реальные данные, отредактируйте
функцию `supplierBox()` в `assets/js/pipe.js` — она одна на все 33 страницы,
править нужно в одном месте.

## Как добавить новый вид трубы

Скопируйте любой блок в массиве `PIPES` в `assets/js/data.js`, поменяйте поля —
труба сама появится в каталоге, фильтрах, списке сравнения и калькуляторе.
Обязательные поля:

| Поле | Что это |
|---|---|
| `slug` | латиницей, без пробелов — попадает в адрес страницы |
| `name`, `shortName` | полное и короткое название |
| `category` | одна из строк массива `CATEGORIES` |
| `materialKey` | ключ из `MATERIALS` (задаёт плотность для расчёта веса) |
| `f: {dMin, dMax, sMin, sMax}` | диапазоны для фильтра по диаметру и стенке |
| `sizes` | массив пар `[диаметр, стенка]` для таблицы веса |
| `visual` | слои и детали для отрисовки (см. выше) |

У многослойных труб (ППУ, ВУС, ЦПП, футерованные) сортамент задан по стальной
основе, поэтому у них есть поле `calcDensity: 7850` — вес считается по стали,
а не по «средней» плотности композита.

## Формулы веса

```
круглая:        m = π · (D − s) · s · ρ / 1 000 000
квадратная:     m ≈ 4 · (a − s) · s · ρ / 1 000 000
прямоугольная:  m ≈ 2 · (a + b − 2s) · s · ρ / 1 000 000
```

Размеры в мм, плотность в кг/м³, результат — кг на погонный метр. Проверено по
справочным значениям ГОСТ: 108×4 → 10,26 кг/м; 57×3,5 → 4,62 кг/м; 219×6 → 31,52 кг/м.
Для профильных труб формула не учитывает радиусы углов и даёт результат на 1–3 % выше.

## Бэкенда нет — и пока не нужен

Весь каталог лежит в `assets/js/data.js`. Это осознанное решение: сортамент и ГОСТы
меняются раз в несколько лет, поэтому сервер нечего обслуживать. Сайт открывается
двойным кликом и бесплатно хостится на GitHub Pages.

Бэкенд имеет смысл добавлять, когда появится что-то из этого:

1. **Цены и остатки** поставщиков — меняются ежедневно, в JS-файле им не место
2. **Форма «запросить цену»** — заявки надо где-то хранить и отправлять на почту
3. **Админка** — чтобы каталог правил не программист
4. **Тысячи типоразмеров** с наличием по складам вместо 33 обзорных карточек

Структура `PIPES` уже нормализована (один объект = одна запись, вложенные списки
вынесены в отдельные поля), поэтому переезд в таблицы Postgres не потребует
переписывать фронтенд — меняется только источник данных.

### Откуда брать данные

Автоматического источника практически нет — это стоит понимать заранее:

| Что | Где | Как |
|---|---|---|
| ГОСТы, сортамент | `protect.gost.ru`, `docs.cntd.ru` | Только тексты стандартов для чтения, API нет, часть платная. Вносится руками один раз |
| Цены и остатки | Прайсы металлотрейдеров (Металлсервис, ДиПОС, А ГРУПП, Брок-Инвест) | XLSX/CSV почтой или по FTP, формат у каждого свой — парсер под каждого отдельный |
| Готовые выгрузки | YML (Яндекс), CommerceML (1С) | Если поставщик отдаёт фид — импорт почти бесплатный |
| Биржевые котировки | LME (медь, алюминий) | Платный доступ |

Рабочая схема: справочная часть заполняется вручную (она стабильна), а цены и наличие
подтягиваются суточным импортом прайсов конкретных поставщиков.

### Если делать бэкенд

Разумный стек — **Python + FastAPI + Postgres**: парсинг XLSX-прайсов это `pandas` /
`openpyxl`, нагрузка здесь минимальная, а типовой набор — модели труб, `GET /pipes`,
`GET /pipes/{slug}`, `POST /leads` для заявок и cron-задача импорта прайсов.
Go оправдан, только если нужен один бинарник без рантайма или высокий RPS — здесь ни того, ни другого.

## Оговорка

Технические данные приведены по действующим ГОСТ, ТУ и типовой отраслевой практике
и носят справочный характер. Доли отраслей в блоке «как часто покупают» — экспертная
оценка, а не статистика продаж. Перед закупкой сверяйтесь с актуальной редакцией
стандарта и сертификатом завода-изготовителя.
